# 📊 TRS - DATA ANALYSIS - POWER BI

# 1. Contexte de l’entreprise

Vous travaillez en tant que Data Analyst au sein de l’entreprise : 👉 TRUST RETAIL SOLUTIONS (TRS).

TRUST RETAIL SOLUTIONS est une entreprise spécialisée dans la distribution de produits technologiques (ordinateurs, téléphones, tablettes et accessoires) à travers plusieurs pays francophones d’Afrique.

L’entreprise opère via plusieurs canaux de vente : Vente en ligne, Boutiques physiques et Partenaires commerciaux.

# 2. Problématique

La direction constate une croissance des ventes, mais **aucune visibilité claire sur les performances réelles.**

Les données disponibles sont :

- Désorganisées
- Incomplètes
- Non standardisées
- Issues de plusieurs saisies manuelles

👉 Il est donc impossible pour la direction de prendre des décisions fiables.

# 3. La mission

Vous avez été mandaté pour nettoyer, structurer et exploiter les données afin de produire un rapport décisionnel.

On vous fournit un fichier Excel contenant les données brutes de ventes.
La base de donnée est disponible ici : [Donnée_TRS_Brutes.xlsx](Data/Donnée_TRS_Brutes.xlsx)

👉 Transformer des données brutes désordonnées en un dataset propre, fiable et exploitable

👉 Produire des insights concrets pour aider à optimiser les ventes et la stratégie commerciale.

# 4. Objectifs de l’analyse

Après nettoyage et transformation des données, vous devez produire un tableau de bord exploitable permettant de répondre aux questions suivantes :

1. Analyse des ventes

● Quel est le total des ventes ?

● Quelle est l’évolution des ventes dans le temps ?

2. Analyse par catégorie de produits

● Quelle catégorie de produits génère le plus de revenus ?

● Quelle est la répartition des ventes par catégorie ?

4. Analyse par pays

● Quels pays performent le mieux ?

● Où se situent les principales sources de revenus ?

5. Analyse par canal de vente

● Quel canal (en ligne, magasin, partenaire) est le plus performant ?

● Quel canal génère le plus de revenus ?

# 5.Livrable attendu

Un rapport structuré permettant à la direction de :

● Comprendre les performances de l’entreprise

● Identifier les segments les plus rentables

● Prendre des décisions stratégiques basées sur les données
